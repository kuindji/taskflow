## Rounds

### Round 1 (2026-10-31): 2 findings, 2 confirmed

- R1-1 confirmed: overlapping Remote Agent starts (double-click Start, two
  UIs, auto-start racing a manual start) each created a Claude session and
  only the last was tracked, so Stop left the other running; Stop during a
  pending start left the agent running; a stopped session's late exit cleared
  its replacement. Pending starts now join, a start finished after Stop closes
  its session, exits of untracked sessions are ignored. Commit: be58d7c5.
- R1-2 confirmed: title generation overwrote a title the user saved while
  generation ran (and named the worktree after the generated title). The
  generated title is now written only if the task title is still empty, and
  the worktree uses the stored title. Commit: be58d7c5.
