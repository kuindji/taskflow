## Rounds

### Round 1 (2026-11-01): 3 findings, 3 confirmed

- R1-1 confirmed: the TUI picked its terminal editor from the backend's
  detected list but spawns it locally, so a remote backend with Micro or
  Neovim made editing fail on a machine that only has Vi. Now only editors
  found on the TUI's own PATH qualify. Commit: b5bcb2ab.
- R1-2 confirmed: after a failed save (offline, backend error) the retry
  saved the `# --- taskflow validation errors ---` block into task notes or
  description. The block is now stripped before validate and save.
  Commit: b5bcb2ab.
- R1-3 confirmed: a subtask's git view listened for change stats under its
  own id, but the backend tracks the shared worktree under the parent's id,
  so the view never refreshed. Same bug fixed in the desktop UI's
  `changeTargetId` (TaskHeader stats, Changes/History panes). Commit: b5bcb2ab.
