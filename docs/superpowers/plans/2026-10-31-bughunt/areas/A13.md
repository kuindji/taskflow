## Rounds

### Round 1 (2026-11-01): 2 findings, 2 confirmed

- R1-1 confirmed: switching to another task or project unmounts the
  workspace's terminals; 100 ms later TerminalPane deleted the session's input
  editor state because its xterm had left the cache, so an unsent prompt in
  the markdown input editor was gone on return although the session lived on.
  The draft is now dropped only once no tab shows the session
  (`releaseInputDraft`). 49a7ee44
- R1-2 confirmed: a file dropped onto a terminal was made relative to the
  active workspace's directory, not the session's own cwd. After moving a
  session from task A to task B, dragging B's `src/app.ts` from the explorer
  typed `src/app.ts`, which the session (still in A's worktree) reads as A's
  file. Drops now use the session's cwd, as clicked links already did
  (`droppedPath`). 49a7ee44
