# App Icon Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create and integrate a monochrome line art app icon for the Taskflow Electron app across macOS, Windows, and Linux.

**Architecture:** Generate a master SVG, render to PNGs at required sizes using `rsvg-convert`, then convert to platform-specific formats (`.icns` via `iconutil`, `.ico` via ImageMagick). Place final assets in `electron/build/` where electron-builder auto-detects them.

**Tech Stack:** SVG, `librsvg` (`rsvg-convert`), macOS `iconutil`, ImageMagick (`magick`)

---

## Chunk 1: Icon Generation and Integration

### Task 1: Create directory and master SVG

**Files:**
- Create: `electron/build/icon.svg`

- [ ] **Step 1: Create the build directory**

Run:
```bash
mkdir -p electron/build
```

- [ ] **Step 2: Create the SVG file**

Write to `electron/build/icon.svg`:
```xml
<svg viewBox="-10 -10 180 180" fill="none" xmlns="http://www.w3.org/2000/svg">
  <rect x="8" y="8" width="144" height="144" rx="32" fill="#111111" stroke="#333333" stroke-width="2"/>
  <polyline points="48,82 70,108 118,52" stroke="white" stroke-width="5.5" stroke-linecap="round" stroke-linejoin="round" fill="none"/>
  <line x1="28" y1="68" x2="52" y2="68" stroke="white" stroke-width="2.5" stroke-linecap="round" opacity="0.6"/>
  <line x1="22" y1="82" x2="40" y2="82" stroke="white" stroke-width="2.5" stroke-linecap="round" opacity="0.4"/>
  <line x1="28" y1="96" x2="48" y2="96" stroke="white" stroke-width="2.5" stroke-linecap="round" opacity="0.25"/>
</svg>
```

- [ ] **Step 3: Verify the SVG renders correctly**

Open `electron/build/icon.svg` in a browser or viewer to confirm: dark rounded square, white checkmark, three fading motion lines to the left, transparent padding around the edges.

### Task 2: Render PNGs at all required sizes

**Files:**
- Create: `electron/build/icon_16.png`, `icon_32.png`, `icon_48.png`, `icon_64.png`, `icon_128.png`, `icon_256.png`, `icon_512.png`, `icon_1024.png`

**Prerequisites:** `librsvg` must be installed. Install via `brew install librsvg` if `rsvg-convert` is not available.

- [ ] **Step 1: Check that rsvg-convert is available**

Run:
```bash
which rsvg-convert || brew install librsvg
```
Expected: path to `rsvg-convert` binary.

- [ ] **Step 2: Render all sizes**

Run:
```bash
cd /Users/kuindji/Projects/taskflow/electron/build && for size in 16 32 48 64 128 256 512 1024; do rsvg-convert -w $size -h $size icon.svg > icon_${size}.png; done
```
Expected: 8 PNG files created in `electron/build/`.

- [ ] **Step 3: Verify PNGs were created**

Run:
```bash
ls -la /Users/kuindji/Projects/taskflow/electron/build/icon_*.png
```
Expected: 8 files, all non-zero size. Spot-check `icon_512.png` in a viewer to confirm it looks correct.

### Task 3: Generate macOS .icns

**Files:**
- Create: `electron/build/icon.icns`

- [ ] **Step 1: Create iconset directory with correctly-named files**

The macOS `.iconset` format requires specific naming: `icon_NxN.png` and `icon_NxN@2x.png` pairs.

Run:
```bash
cd /Users/kuindji/Projects/taskflow/electron/build && mkdir -p icon.iconset && cp icon_16.png icon.iconset/icon_16x16.png && cp icon_32.png icon.iconset/icon_16x16@2x.png && cp icon_32.png icon.iconset/icon_32x32.png && cp icon_64.png icon.iconset/icon_32x32@2x.png && cp icon_128.png icon.iconset/icon_128x128.png && cp icon_256.png icon.iconset/icon_128x128@2x.png && cp icon_256.png icon.iconset/icon_256x256.png && cp icon_512.png icon.iconset/icon_256x256@2x.png && cp icon_512.png icon.iconset/icon_512x512.png && cp icon_1024.png icon.iconset/icon_512x512@2x.png
```

- [ ] **Step 2: Convert iconset to .icns**

Run:
```bash
cd /Users/kuindji/Projects/taskflow/electron/build && iconutil -c icns icon.iconset -o icon.icns
```
Expected: `icon.icns` created with no errors.

- [ ] **Step 3: Clean up iconset directory**

Run:
```bash
rm -rf /Users/kuindji/Projects/taskflow/electron/build/icon.iconset
```

### Task 4: Generate Windows .ico

**Files:**
- Create: `electron/build/icon.ico`

**Prerequisites:** ImageMagick must be installed. Install via `brew install imagemagick` if `magick` is not available.

- [ ] **Step 1: Check that ImageMagick is available**

Run:
```bash

```
Expected: path to `magick` binary.

- [ ] **Step 2: Create multi-size .ico**


Expected: `icon.ico` created containing all 6 sizes.
