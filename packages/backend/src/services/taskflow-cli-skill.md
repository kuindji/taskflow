# Taskflow CLI

Taskflow puts `taskflow-cli` on your PATH, pre-configured for this session.

# Basic commands within task context

`taskflow-cli task` Get current task info
`taskflow-cli log info "<text>"` Log info
`taskflow-cli log error "<text>"` Log error
`taskflow-cli log commit "<text>" --hash <hash>` Log commit
`taskflow-cli log file "<path/to/file>"` Log edited file
