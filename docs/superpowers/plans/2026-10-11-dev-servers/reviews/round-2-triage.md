# Round 2 triage

- **DS2-01 (major): confirmed.** `connectDevRenderer` (`WebSocketProvider.tsx:8`) sets primary and opens a connection with no machine row, so the `attached`-only filter hides every row in the browser UI Section 5 drives. Fix: `useLiveDevServers` also treats `primaryId` as live when no machine row exists for it; a component test pins it, and the offline-machine tests are unchanged. Section 5 notes that items 12-13 need the Electron app.
- **DS2-02 (minor): confirmed.** `stopDevServer` writes `{ error }` whenever its token is still current, and closing the popover doesn't touch tokens, so a failure after close (e.g. the 30 s `REQUEST_TIMEOUT`, `connection.ts:176`) shows on reopen. Fix: `handleOpenChange` clears errors on open and close (`"stopping"` is kept). Manual item 10 adds the scenario (Radix portals keep it out of unit tests).
- **DS2-03 (major): confirmed.** Reproduced with tsc 5.9.3 in a scratch file: after `finish = undefined`, `finish?.()` is TS2349 (`never`). The first phase compiles; the second doesn't. Fix: one holder object per phase (`first`, `second`); the holder version typechecks.
- **DS2-04 (minor): confirmed.** Reproduced with the repo's eslint config on a scratch test file: `no-unsafe-argument` for `toEqual(expect.arrayContaining(...))` and `no-meaningless-void-operator` for `async () => void setState(...)`. Fix: three `toContain` assertions; a block-bodied fake.
- **DS2-05 (minor): confirmed.** `consumeFlags` (`cli-flags.ts:16`) treats `--` as end-of-flags and `-x` as positional, so the TS bin would `DELETE /api/dev-servers/-x` and accept `list --`; the sh `case` rejects both. Fix: a local `hasEndOfFlags(args, valueFlags)` in the bin (so `--label --` stays a value) and a `-`-prefix check on `remove`'s id. Cases added to both harnesses, plus a `--label --` acceptance test. The shared parser is unchanged.
- **DS2-06 (minor): confirmed.** Both CLIs ask `GET /api/sessions/$TASKFLOW_SESSION_ID/owner` before dispatch (`taskflow-cli.sh:89`, `taskflow-cli-bin.ts:1401`). Fix: item 8 requires no `/api/dev-servers` request and allows the owner lookup.
