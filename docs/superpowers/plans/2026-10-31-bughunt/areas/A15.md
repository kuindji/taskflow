## Rounds

### Round 1 (2026-11-01): 3 findings, 3 confirmed

- R1-1 confirmed: Close Tab (Cmd/Ctrl+W, or the Electron menu item) closed
  the active tab directly, skipping the confirmations the tab's close button
  shows: an editor or markdown tab with unsaved edits lost them, and a
  running Vim/Neovim/Nano editor session was killed. Both paths now go
  through `requestCloseTab` (`close-tab.ts`). 69c6b68e
- R1-2 confirmed: launching a flow that has inputs from the master
  workspace stored the pending input state, but the master layout returned
  before the `FlowInputDialog` was rendered, so no dialog appeared and the
  flow never started. Both layouts now render the dialog. 69c6b68e
- R1-3 confirmed: View → Markdown Input (and the Cmd/Ctrl+Shift+E fallback)
  toggled the left pane's session even when the right split pane was
  focused. It now uses the focused pane (`focusedPaneKey` in `ui-store.ts`,
  which also replaces three copies of the same helper). 69c6b68e
