## Own findings (Claude)

- C2-1 (minor) **confirmed**. Electron 45 keys Touch ID credential metadata to a per-profile secret (`electron_authenticator_request_delegate.cc:69-95`, pref `electron.webauthn.touchid.metadata_secret`). A passkey the owner registers on a real site from the sandboxed test build can never be used from the installed app, so it would be left on the owner's real account. Fixed: Section 4 Step 4 tells the owner to delete that passkey from the site afterwards. Step 6 repeats the real-site check in the installed app.
- C2-2 (minor) **confirmed**. Section 3 Step 7 runs the probe's platform `create()` in the signed, configured build. Chromium's make-credential flow prompts Touch ID first, so a system Touch ID dialog appears on the owner's screen for 20 s. This breaks the no-focus-stealing rule, and a touch would create a stray keychain item. Fixed: the probe has a `--uvpaa-only` flag, and Section 3 uses it. The Touch ID dialog is left to the owner's hand check.
