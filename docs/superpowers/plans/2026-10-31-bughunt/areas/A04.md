## Rounds

### Round 1 (2026-10-31): 2 findings, 2 confirmed

- R1-1 confirmed: overlapping Remote Agent starts (double-click Start, two
  UIs, auto-start racing a manual start) each created a Claude session and
  only the last was tracked, so Stop left the other running; Stop during a
  pending start left the agent running; a stopped session's late exit cleared
  its replacement. Pending starts now join, a start finished after Stop closes
  its session, exits of untracked sessions are ignored. Commit: be58d7c5.
- R1-2 confirmed: title generation overwrote a title the user saved while
  generation ran (and named the worktree after the generated title). The
  generated title is now written only if the task title is still empty, and
  the worktree uses the stored title. Commit: be58d7c5.

### Round 2 (2026-10-31): 3 findings, 3 confirmed

- R2-1 confirmed: the nvm fallback in `buildShellPath` ignored a default
  alias stored with its `v` prefix (`nvm alias default v22.14.0`), so with nvm
  set up only in `.zshrc` (not read by `zsh -l -c`) a Finder-launched app
  could not find Node-based agents. The alias's `v` is now stripped.
  Commit: 7b560c43.
- R2-2 confirmed: shell discovery kept the first `/etc/shells` entry per
  name, so `$SHELL=/opt/homebrew/bin/bash` listed after `/bin/bash` was dropped
  and sessions ran `/bin/bash`. The `$SHELL` install now replaces an earlier
  one of the same name. Commit: 7b560c43.
- R2-3 confirmed (minor): Obsidian in `~/Applications/Obsidian.app` was
  reported as not installed, hiding "Open in Obsidian". Both app folders are
  now checked. No regression test: this machine has Obsidian in
  `/Applications`, so a test cannot tell the paths apart. Commit: 7b560c43.

### Round 3 (2026-10-31): 2 findings, 2 confirmed

- R3-1 confirmed: a Remote Agent session that exited before `createSession`
  resolved (the PTY spawns before the master-session ref is saved) had its
  exit dropped because `currentSessionId` was still null; the service then
  tracked the dead session as running, skipped auto-restart, and Start
  returned the stale session. An exit during the start is now remembered and
  handled once the start finishes. Commit: c3cd1725.
- R3-2 confirmed: agent and runtime `--version` probes ran with the inherited
  PATH, not the expanded one used to find them, so a Finder-launched app
  reported `env: node: No such file or directory` as the version of
  Node-based agents (and a Node-based Claude failed the Remote Control
  version gate). Probes now get the expanded PATH and a non-zero exit yields
  no version. Commit: c3cd1725.

### Round 4 (2026-10-31): 2 findings, 2 confirmed (minor)

- R4-1 confirmed: the shell PATH probe ran `$SHELL -l -c`, which zsh and
  bash run non-interactively, so PATH entries added only in `.zshrc`/`.bashrc`
  (custom npm prefix, pnpm, mise, installer-added bins) were missing for a
  Finder-launched app and those agents showed as not installed. The probe now
  runs an interactive login shell (stdin closed, PATH framed by markers
  against startup noise), falling back to login-only, then the inherited
  PATH. Commit: 62303204.
- R4-2 confirmed (minor): on Linux, Obsidian installed from a distro package
  (`/usr/share/applications/obsidian.desktop`) was reported as not installed,
  hiding "Open in Obsidian". System desktop-entry folders are now checked.
  Flatpak/Snap installs keep their registry in a sandboxed config folder and
  are still not detected. No regression test: the detector reads the real
  platform and filesystem. Commit: 62303204.

Round 4 found only minor bugs (no data loss, store corruption or killed
sessions): area marked clear.
