## Rules

**When a backend hosts.** All three must hold:
- `useIsElectron()`;
- the backend is the Electron app's local backend (the attached-backend record with `isLocal: true`; find how `backend-store.ts` exposes it);
- its last `BrowserTabListResponse.hostAvailable` is true.

**`syncBrowserTabs`**
- A registry tab becomes `{ id: "browser:" + tab.id, type: "browser", browserTabId: tab.id, label: tab.title || tab.label, url: tab.url, agentConnected: tab.agentConnections > 0 ? true : undefined }`.
- New tabs go into the base workspace key.
- An existing tab stays in whichever pane (`:right` included) it currently sits in, and only label, url and the marker are refreshed.
- Tabs whose `browserTabId` is in `knownIds` but gone from the list are removed. Tabs from other backends are never in `knownIds`, so they are never touched. Active-tab fallback works the same as `closeTab`.
- The browser tab store keeps the last list per backend; `knownIds` is that list's ids. A backend reset removes that backend's tabs (sync with an empty list and the old ids), and nothing else.
- Unchanged state returns the same object references (the zustand selector rule in memory `project_zustand_reactivity`).

**`HostedBrowserPane`**
- **Toolbar:** today's toolbar, minus `Activity`-specific webview code. The URL input shows `tab.url`. Enter → `bridge.navigate`. Back → `bridge.back`. Reload → `bridge.reload`. External → `openExternalUrl(tab.url)`. `canGoBack` comes from `onNavState`.
- **Placeholder:** a `div` measured with `ResizeObserver`, plus window `resize`.
- **While visible:**
  - when no overlay rect intersects the placeholder's rect: `bridge.show(id, url, rect)` on mount and on every rect change (coalesced to one call per animation frame);
  - when an overlay intersects: `bridge.freeze(id)`, and the returned image fills the placeholder (`<img>`, `object-fit: fill`) until no overlay intersects; then `show` again.
  - an empty string from `freeze` (the tab has no view yet, or the capture failed or timed out) leaves the placeholder blank.
- **Hidden** (React `<Activity>` hidden runs effect cleanups) **or unmounted**: `bridge.hide(id)`.
- A renderer reload runs no cleanup. Main detaches every view when the UI reloads (Section 5), so the rebuilt UI only has to `show` the panes it displays.
- Hiding the pane never closes the tab.

**Agent marker.** A small dot before the label, `aria-label` and tooltip `Agent connected`, shown when `agentConnected`.
