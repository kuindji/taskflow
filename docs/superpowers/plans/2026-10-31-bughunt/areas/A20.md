## Rounds

### Round 1 (2026-11-01): 2 findings, 1 confirmed

- R1-1 confirmed: react-markdown's default `urlTransform` read the drive
  letter of `C:/wiki/other.md` as an unknown scheme and blanked the href, so
  every wiki link under a Windows wiki root (and every explicit drive-letter
  link or image) rendered dead. The preview now uses `markdownUrlTransform`,
  which keeps drive-letter paths and defers to the default otherwise. d7b9ad04
- R1-2 rejected: external links do nothing without the Electron bridge; only
  reachable in a plain browser, which is not a shipped surface.
