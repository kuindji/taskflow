## Rounds

### Round 1 (2026-10-31): 2 findings, 2 confirmed

- R1-1 confirmed: overlapping Remote Agent starts (double-click Start, two
  UIs, auto-start racing a manual start) each created a Claude session and
  only the last was tracked, so Stop left the other running; Stop during a
  pending start left the agent running; a stopped session's late exit cleared
  its replacement. Pending starts now join, a start finished after Stop closes
  its session, exits of untracked sessions are ignored. Commit: be58d7c5.
- R1-2 confirmed: title generation overwrote a title the user saved while
  generation ran (and named the worktree after the generated title). The
  generated title is now written only if the task title is still empty, and
  the worktree uses the stored title. Commit: be58d7c5.

### Round 2 (2026-10-31): 3 findings, 3 confirmed

- R2-1 confirmed: the nvm fallback in `buildShellPath` ignored a default
  alias stored with its `v` prefix (`nvm alias default v22.14.0`), so with nvm
  set up only in `.zshrc` (not read by `zsh -l -c`) a Finder-launched app
  could not find Node-based agents. The alias's `v` is now stripped.
  Commit: 7b560c43.
- R2-2 confirmed: shell discovery kept the first `/etc/shells` entry per
  name, so `$SHELL=/opt/homebrew/bin/bash` listed after `/bin/bash` was dropped
  and sessions ran `/bin/bash`. The `$SHELL` install now replaces an earlier
  one of the same name. Commit: 7b560c43.
- R2-3 confirmed (minor): Obsidian in `~/Applications/Obsidian.app` was
  reported as not installed, hiding "Open in Obsidian". Both app folders are
  now checked. No regression test: this machine has Obsidian in
  `/Applications`, so a test cannot tell the paths apart. Commit: 7b560c43.
